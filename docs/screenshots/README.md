# Screenshots

Drop the 6 marketing screenshots here as PNGs (recommended 1280×800).
The README links to:

| File                          | Used in the README for                  |
| ----------------------------- | --------------------------------------- |
| `home.png`                    | Home                                    |
| `restaurant.png`              | Restaurant detail                       |
| `checkout.png`                | Checkout                                |
| `partner.png`                 | Partner dashboard                       |
| `rider.png`                   | Rider tracking map                      |
| `admin.png`                   | Admin analytics                         |

Run the dev server (`npm run dev`) and capture the screens with your
favourite screenshot tool, then drop the PNGs in this folder.

The folder is committed (no `.gitkeep` file because the folder
itself is tracked) so the README image links resolve on the public
GitHub repo.
